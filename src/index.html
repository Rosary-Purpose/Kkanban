Backup & Restore
More info

Export saves every board (including archived ones) and their background images into one file you can store anywhere. Import replaces everything currently in kkanban with a chosen backup file - it can't be undone.

kkanban also saves an automatic backup once a day
(the last 14 days are kept) in the backups folder next to the data file above. Restore one with Import Backup.
